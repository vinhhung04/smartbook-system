### SB07 count cutoff and physical counting freeze (stock-audit agent owns)

Protect all mutation paths, including other services via Inventory integration; a PostgreSQL guard/trigger is acceptable to enforce this invariant centrally. Locks/freeze must be released on count completion/cancel, and missing legacy cutoff requires recount. Add backward-compatible fields/migrations and minimally update existing count UI messages. Own stock-audit controller/services/schema audit fields/migration/tests and stock audit UI only. Coordinate inventory schema disjoint edits with transfer agent.

### SB12 transfer discrepancy lifecycle (transfer agent owns)

Accept usable copies into ordinary receiving stock; record damaged/rejected physically delivered copies in quarantined non-available custody, and missing quantities as discrepancy cases, never stock. Separate receipt confirmation from discrepancy resolution; usable stock can be put away immediately. Warehouse-scoped manager reviews a reason/evidence-based resolution and closes case; preserve transfer RECEIVED compatibility and add discrepancy status/counts. Store shipment, delivered, accepted, damaged, rejected, missing quantities and actors durably; prevent duplicate cases/stock/quarantine on retries/concurrent receive. Support explicit resolutions (found/redelivered goods, returned to source, write-off/approved loss) with appropriate guarded stock movement/outbox/audit; don't just change a label without custody accounting. Existing repick integration and receiving contracts must continue working. Add minimal UI panel on existing transfer receive/detail surface and scoped API. Own transfer-receiving + new discrepancy service/routes/schema/migration/tests/UI; do not edit stock-audit, supplier receiving or borrow-integration files unless coordinated.

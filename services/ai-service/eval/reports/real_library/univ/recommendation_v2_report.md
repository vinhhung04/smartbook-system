## Baselines

- **RANDOM** – seeded shuffle of eligible books.
- **POPULARITY** – train-window loan count.
- **V1_PRODUCTION** – current `recommendation.py` (hardcoded weights; semantic=[] offline, as before).
- **V2** – this work. **V2+CATEGORY_CAP3** – diversity constraint. **V2_NO_CANDIDATE_PRUNING** – ranks every eligible book.
- **CONTENT_ONLY** (preference+author+semantic) and **CF_ONLY** (item-item collaborative) – single-family variants, tuned the same way.
- **ORACLE_TRUE_PREFERENCE** – reads the simulator's latent truth (static category preference × popularity × favourite author); a reference ceiling, not deployable. It is not Bayes-optimal: it ignores habit momentum, wishlist boosts and stock, so an observable-data model can approach or exceed it on some metrics.

## Limitations

- Real loans of one library, borrowing only: no wishlist/review/reservation rows, so the preference signals V2 gets in production from those are absent here.
- Weights are tuned on this library's own validation window, not copied from production; production weights stay the synthetic ones.
- Categories are DDC divisions and the text is title + author only (no descriptions); copies never borrowed are unknown, so availability is a lower bound.
- Semantic similarity is TF-IDF over title/author/category/description (same code offline and online); production V1's Qwen embeddings are not evaluated offline.
- Availability is the point-in-time state at the cutoff, while targets span the whole test window.
- Weights are tuned on one validation window of one seed; the bootstrap CI covers user sampling, not dataset/seed variance.
- `feature_scale` is fixed from tuning; in production the popularity/recency count ranges drift as history grows.

## Conclusion

- V2 vs V1_PRODUCTION on 200 test users: hit_rate@10 better (Δ=+0.2100, 95% CI [+0.1500, +0.2750]); ndcg@10 better (Δ=+0.0742, 95% CI [+0.0500, +0.1016]); recall@10 better (Δ=+0.1122, 95% CI [+0.0765, +0.1528]); mrr better (Δ=+0.0872, 95% CI [+0.0568, +0.1223]).
- V2 vs POPULARITY on 200 test users: hit_rate@10 better (Δ=+0.0950, 95% CI [+0.0350, +0.1600]); ndcg@10 better (Δ=+0.0367, 95% CI [+0.0124, +0.0631]); recall@10 better (Δ=+0.0555, 95% CI [+0.0240, +0.0916]); mrr better (Δ=+0.0436, 95% CI [+0.0112, +0.0786]).
- Coverage@10 / Personalization@10: POPULARITY 0.0017/0.0731, V1_PRODUCTION 0.0336/0.8641, V2 0.1039/0.9598.
- Ablation: not run (--skip-ablations).
- Item cold start: Recall@10 on masked new books - V2 with imputation + new-arrival slot 0.0, imputation only 0.0, zero evidence 0.0, POPULARITY 0.0, RANDOM 0.0 (V2 when their history is known: 0.0244).
- Cold start, new users (n=2702): NDCG@10 V2 0.0314 vs POPULARITY 0.0314 (equal).
- Cold start, sparse users (n=231): NDCG@10 V2 0.0942 vs POPULARITY 0.0312 (V2 higher).
- Acceptance rule on this real library: met (informational - the production model choice is made on the synthetic dataset and is unchanged).
